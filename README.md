# 尼山聖境・大學堂 3D 導覽

three.js 單檔 PWA（three.js r149 已內嵌於 `index.html`），沿朝聖動線導覽尼山聖境大學堂：

- 戶外：宮殿式大門「德侔天地」、天命大道 260 階、三千杏樹、72 公尺孔子銅像
- 門廳：青銅巨門、尼山六景雙面繡屏風、集賢廳麒麟與童子舉鼓
- 大學之道 99 階、七十二賢廊（105 m）、杏壇講學圖與青鳥
- 五常五行殿堂：仁（土・麒麟）、禮（火・朱雀）、信（木・青龍）、義（金・白虎）、智（水・玄武）

操作：
- 導覽模式：單指旋轉、雙指縮放／平移；「剖面」移除屋頂俯瞰；「語音」zh-TW 朗讀；「自動」自動巡覽
- 漫遊模式：左下虛擬搖桿移動（推到底為快走）、右側拖曳環顧；電腦可用 WASD／方向鍵＋滑鼠，Shift 快走
- 右上小地圖：雙指縮放、單指拖曳平移、◎ 跟隨自己、1× 還原；顯示所在位置與朝向，去過的殿堂會亮起（進度存在本機）；點地圖可前往該站，漫遊時則直接瞬移
- 「☾ 夜」切換夜景：星空、月亮、燈籠與長明燈點亮；天命大道杏花持續飄落
- 廊頂鎏金青鳥會緩慢拍翅，天命大道上空有鶴群盤旋
- 智廳玄武為可互動神獸（龜蛇合體）：點龜殼鳴鐘、金紋發光、水波擴散；點龜頭縮頸；點靈蛇昂首吐信；點腳踏步；連點五下喚醒神獸
- 禮廳朱雀為可互動神鳥：點頭長鳴、點翅膀振翅、點尾羽開屏、點火焰台火焰竄高；連點五下浴火重生、繞殿飛翔（音效依五音配五行：朱雀徵調、玄武羽調、青龍角調）
- 信廳青龍為可互動神龍：點龍頭張口長吟、點龍身游動、點龍爪龍珠旋光、點祥雲台雲湧；連點五下喚醒神龍、騰雲繞殿
- 義廳白虎為可互動神獸：點頭虎嘯、點前爪揮爪、點尾巴甩尾、點身體起身、點山岩台座金石鳴響；連點五下喚醒白虎、繞殿奔馳（商調）
- 可替換更精細的 glb 模型：見 [models/README.md](models/README.md)
- 點任何物件（麒麟、書架、立柱、壁畫、瓷板畫…）即跳出解說，可一鍵前往該站

離線：首次開啟後由 `sw.js` 快取，沒網路也能開；有網路時頁面一律抓最新版。改版時把 `sw.js` 的 `CACHE` 版本號加一，使用者重新開啟 App 會看到「有新版本，點此更新」。

※ 各廳相對位置依五行方位示意配置，非實際平面圖。
