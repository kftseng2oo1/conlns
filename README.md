# 尼山聖境・大學堂 3D 導覽

three.js 單檔 PWA（three.js r149 已內嵌於 `index.html`），沿朝聖動線導覽尼山聖境大學堂：

- 戶外：宮殿式大門「德侔天地」、天命大道 260 階、三千杏樹、72 公尺孔子銅像
- 三千杏樹：依真實杏樹造型，深色枝條層層分岔、白花（暗紅花萼、黃蕊）一簇簇綴在枝上、整棵通透；近處約 160 棵用精細模型、遠處用手繪通透樹冠，隨鏡頭自動切換；點任何一棵杏樹會搖動並落下杏花
- 門廳：青銅巨門、尼山六景雙面繡屏風、集賢廳麒麟與童子舉鼓
- 大學之道 99 階、七十二賢廊（105 m）、杏壇講學圖與青鳥
- 五常五行殿堂：仁（土・麒麟）、禮（火・朱雀）、信（木・青龍）、義（金・白虎）、智（水・玄武）

操作：
- 導覽模式：單指旋轉、雙指縮放／平移；「剖面」移除屋頂俯瞰；「語音」zh-TW 朗讀；「自動」自動巡覽
- 漫遊模式：左下虛擬搖桿移動（推到底為快走）、右側拖曳環顧；電腦可用 WASD／方向鍵＋滑鼠，Shift 快走
- 右上小地圖：雙指縮放、單指拖曳平移、◎ 跟隨自己、1× 還原；顯示所在位置與朝向，去過的殿堂會亮起（進度存在本機）；點地圖可前往該站，漫遊時則直接瞬移
- 「☾ 夜」切換夜景：星空、月亮、燈籠與長明燈點亮；天命大道杏花持續飄落
- 廊頂鎏金青鳥會緩慢拍翅，天命大道上空有鶴群盤旋
- 智廳玄武為可互動神獸（龜蛇合體）：點龜殼鳴鐘、金紋發光、水波擴散；點龜頭縮頸；點靈蛇昂首吐信；點腳踏步；連點五下喚醒神獸
- 禮廳朱雀為可互動神鳥：點頭長鳴、點翅膀振翅、點尾羽開屏、點火焰台火焰竄高；連點五下浴火重生、繞殿飛翔（音效依五音配五行：朱雀徵調、玄武羽調、青龍角調）
- 信廳青龍為可互動神龍：點龍頭張口長吟、點龍身游動、點龍爪龍珠旋光、點祥雲台雲湧；連點五下喚醒神龍、騰雲繞殿
- 義廳白虎為可互動神獸：點頭虎嘯、點前爪揮爪、點尾巴甩尾、點身體起身、點山岩台座金石鳴響；連點五下喚醒白虎、繞殿奔馳（商調）
- 仁廳與集賢廳麒麟為可互動瑞獸（共四隻，各自獨立）：點頭長鳴、點蹄踏步生光、點身體抖鬃、點石台吐出玉書「天下為公」；連點五下喚醒、騰躍繞殿（宮調）
- 五行圓滿彩蛋：四神獸都喚醒過（進度存在本機），再喚醒麒麟，五色光柱自五方升起
- 孔子銅像可互動：點頭部頷首、點雙手或身體作揖回禮，並浮出一句《論語》（開語音會朗讀）；頭部會隨參觀者轉動，漫遊走近會伸出講學的手；連續作揖三次即「拜師入門」，銅像轉為深藍金邊、背後浮現「仁」字金環。五獸都喚醒後再拜師，觸發杏花滿天的最終彩蛋
- 杏壇講學：天命大道左側杏林中的石壇，彩繪孔子與六位弟子（顏淵、子貢、子路、樊遲、子游、子張）；點弟子會舉手提問，孔子講學作答（字幕＋語音）
- 禮廳鐘鼓：北牆兩側仿曾侯乙編鐘的兩層鐘架（下層五口甬鐘、上層六口鈕鐘，依宮商角徵羽調音）、東西兩側虎座建鼓、門頭九面懸鼓；點鐘鼓即敲響（鐘會擺動、鼓皮震動），點紅頭撞鐘棒自動演奏一段
- 智廳・孔子問禮於老子：孔子（縮小的孔子模型）與新做的老子（白眉長髯、布衣、藜杖掛葫蘆）相對而立；點孔子，他作揖發問、老子作答（字幕＋語音），共五問；五問聽完，孔子嘆「吾今日見老子，其猶龍邪」。點老子會說一句《道德經》
- 七十二賢廊：依參考圖做顏回（盤坐讀簡）、子路（持劍武士）、子貢（華服論說）、曾子（跪坐書寫）四型塑像，72 尊隨機散置廊道兩側（顏回、仲由、端木賜、曾參用各自的造型），台座前刻姓名（名弟子附字）；點塑像或名牌顯示名字。以 InstancedMesh 繪製，效能負擔小
- 目錄：點篇章標題展開／收合；從頂端握把往下拉可關閉；兩指捏合或張開可縮放目錄文字（記在本機）
- 漫遊：點地面就自動走過去（地上出現金色光圈，被擋住會停下提示）；拖曳畫面任何地方轉頭環顧；左下固定搖桿也能走；點物件看解說，點小地圖瞬間移動
- 雙面繡屏風：六扇折屏、紫檀回紋框、雕花屏帽與裙板；正面繡尼山六景（尼丘、觀川、五老、坤靈、中和、智源），背面繡牡丹、喜鵲登梅、丹鳳祥雲、松鶴延年、荷塘清趣、竹報平安（雙面異繡）；畫面以程式一針一線「繡」成，點扇面會亮起並說明
- 集賢廳童子擊鼓：三十尊銅鑄童子（大頭圓臉、總角雙髻、交領短衫），舉鼓、擊鼓兩式交錯；點童子會擊鼓或舉鼓搖鼓，連點三下鼓陣由近而遠齊鳴
- 通天書架・四書五經：分九區，西牆四書（論語、孟子、大學、中庸，線裝書）、東牆五經（詩、書、禮、易、春秋，竹簡卷）；每區有匾額、專屬色系與主題圓章（易經太極八卦會轉），點任一區亮起並顯示成書、篇數、核心思想與名句
- 神獸會用眼神跟隨參觀者（頭部轉向鏡頭，有角度上限）；漫遊時走近會打招呼：白虎起身低吼並一直站著、走遠才坐回去，青龍低吟、朱雀長鳴、玄武靈蛇昂首、麒麟長鳴
- 可替換更精細的 glb 模型：見 [models/README.md](models/README.md)
- 點任何物件（麒麟、書架、立柱、壁畫、瓷板畫…）即跳出解說，可一鍵前往該站

離線：首次開啟後由 `sw.js` 快取，沒網路也能開；有網路時頁面一律抓最新版。改版時把 `sw.js` 的 `CACHE` 版本號加一，使用者重新開啟 App 會看到「有新版本，點此更新」。
